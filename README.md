# 🏆 Dota 2 TI 2026 Analytics

Interactive dashboard for analyzing The International 2026 tournament data.

---

## 📊 Dashboard Features

- **Tournament Overview** – Team rankings, win rates, and match statistics
- **Odds Movement** – Track win probability changes during matches
- **Advanced Team Stats** – KDA, GPM, XPM, hero damage, and team comparisons

---

## 🛠️ Built With

**Python** · **Streamlit** · **Plotly** · **Pandas**

---

## 📁 Data Source

Match data fetched from **STRATZ GraphQL API** – 147 matches, 16 teams from The International 2026.
